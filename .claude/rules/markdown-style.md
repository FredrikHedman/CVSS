---
name: Markdown Style
description: Guidelines for writing and formatting Markdown files.
globs:
  - "**/*.md"

---

- Wrap lines to at most 95 characters.
- Prefer fenced code blocks with a language tag when possible.
- Wrap all code-related names in backticks.
- Tables have a total width <= 95 characters.
- Split lines in Tables over several rows if necessary.
- Ensure tables have aligned columns.
